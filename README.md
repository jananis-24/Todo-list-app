# To-Do List App

A simple to-do list in plain HTML, CSS and JavaScript. This was my first web project.

**Live demo:** https://jananis-24.github.io/Todo-list-app/

## Features

- Add a task (empty tasks are blocked)
- Click a task to mark it done; click × to delete it
- Tasks stay after a page refresh (saved in localStorage)

## Tech

HTML · CSS · JavaScript, no frameworks

## Run it locally

Download the repo and open `index.html` in a browser.
